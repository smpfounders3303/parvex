# PARVEX — DESIGN SYSTEM

Version: 1.0

---

# DESIGN PRINCIPLE

The Parvex website should not look like a template.

Every section should feel intentionally designed.

Our inspiration comes from premium digital agencies, but our identity must remain unique.

The website should feel:

• Premium
• Elegant
• Modern
• Minimal
• Professional
• Creative
• Fast
• Timeless

Less design.

More quality.

---

# DESIGN FORMULA

70% Cuberto

10% Linear

10% Stripe

5% Apple

5% Clay

This is inspiration only.

Never copy layouts.

Never copy colors.

Never copy typography exactly.

Never recreate another company's identity.

---

# VISUAL LANGUAGE

The design should communicate confidence.

Large typography.

Large whitespace.

Minimal colors.

Strong visual hierarchy.

Editorial layouts.

Beautiful photography.

Smooth interactions.

Everything should feel expensive without looking complicated.

---

# LAYOUT

Use a centered layout.

Maximum container width:

1400px

Content width:

1200px

Reading width:

700–800px

Sections should never feel cramped.

Give content room to breathe.

---

# GRID SYSTEM

Desktop

12-column grid

Tablet

8-column grid

Mobile

4-column grid

Always align content consistently.

---

# SPACING SYSTEM

Spacing is one of the most important parts of premium design.

Use an 8px spacing system.

Example:

4px

8px

12px

16px

24px

32px

48px

64px

96px

128px

160px

Never use random spacing values.

Whitespace creates luxury.

---

# SECTION SPACING

Hero

Very large spacing.

Services

Large spacing.

Projects

Large spacing.

About

Comfortable spacing.

Footer

Simple spacing.

Every section should clearly separate from the next.

---

# BORDER RADIUS

Keep radius consistent.

Small Components

12px

Cards

20px

Buttons

9999px (pill)

Images

20px

Avoid mixing many different radius values.

---

# TYPOGRAPHY

Typography is more important than animation.

Use only one primary font family.

Suggested Fonts:

Geist ⭐

Inter

Satoshi

General Sans

Use only one.

---

# FONT SCALE

Hero Title

64–96px

Section Title

40–56px

Card Title

24–32px

Body

18–20px

Small Text

14–16px

Avoid tiny unreadable text.

---

# FONT WEIGHTS

Light

300

Regular

400

Medium

500

SemiBold

600

Bold

700

Avoid excessive bold everywhere.

Create hierarchy naturally.

---

# TEXT ALIGNMENT

Mostly left aligned.

Center only where it improves clarity.

Never center large paragraphs.

---

# COLORS

Primary Background

White

Primary Text

Near Black

Secondary Text

Gray

Accent

One premium accent color.

No rainbow gradients.

No colorful UI.

No unnecessary shadows.

---

# SHADOWS

Use subtle shadows only.

Cards should appear elevated naturally.

Avoid heavy floating effects.

---

# BUTTONS

Primary Button

Solid

Large

Rounded

Confident

Secondary Button

Outline

Ghost

Minimal

Hover should feel smooth.

Never flashy.

---

# CARDS

Cards should feel premium.

Large padding.

Beautiful spacing.

Soft radius.

Minimal borders.

Clean typography.

Large imagery.

Never overcrowd.

---

# IMAGES

Images are one of our strongest assets.

Always use:

Large photography

Large project previews

High resolution

Optimized formats

Never stretch images.

Never distort aspect ratio.

---

# ICONS

Use icons only when necessary.

Do not decorate every section with icons.

Use:

Lucide React

Keep icon style consistent.

---

# NAVIGATION

Transparent initially.

Solid after scrolling.

Simple logo.

Minimal menu.

Clear CTA button.

Avoid large navigation bars.

---

# HERO SECTION

This is the most important section.

Must answer immediately:

Who are we?

What do we build?

Why choose us?

Should contain:

Large heading

Short supporting text

Primary CTA

Secondary CTA

Premium visual composition

No clutter.

---

# SERVICES SECTION

Present services with confidence.

Avoid tiny icon cards.

Think Apple.

Think Clay.

Large cards.

Strong typography.

Minimal descriptions.

---

# PROJECT SECTION

Projects should dominate the page.

Large thumbnails.

Minimal text.

Case study feeling.

Premium hover interactions.

Never use tiny portfolio cards.

---

# PHOTOGRAPHY SECTION

Editorial gallery.

Large images.

Beautiful composition.

Mix photography and videography.

Do not create an Instagram grid.

---

# ABOUT SECTION

Keep short.

No long paragraphs.

Communicate trust.

Simple.

Human.

Professional.

---

# CTA SECTION

Simple.

Strong message.

One button.

One purpose.

Encourage contact.

---

# FOOTER

Minimal.

Clean.

Organized.

Never overcrowded.

---

# RESPONSIVE DESIGN

Desktop First

Tablet

Mobile

Never simply scale down.

Redesign layouts where necessary.

Maintain premium feeling across all devices.

---

# ACCESSIBILITY

Minimum text contrast.

Keyboard navigation.

Semantic HTML.

Visible focus states.

Alt text for images.

Respect prefers-reduced-motion.

---

# MICRO INTERACTIONS

Hover should feel alive.

Buttons

Cards

Links

Images

Navigation

Small.

Elegant.

Never distracting.

---

# ANIMATION PHILOSOPHY

Animation supports content.

Animation never becomes the content.

Motion should improve understanding.

Not impress developers.

Future animations will use:

GSAP

Framer Motion

Lenis

Do not design layouts that depend on heavy animations.

---

# PERFORMANCE

Optimize everything.

Lazy load images.

Responsive images.

Minimal JavaScript.

Small bundle size.

High Lighthouse score.

Target:

95+

---

# COMPONENT DESIGN

Every component should be:

Reusable

Responsive

Accessible

Scalable

Consistent

Production Ready

Never duplicate UI unnecessarily.

---

# DESIGN CHECKLIST

Before approving any page ask:

✓ Does it feel premium?

✓ Is spacing consistent?

✓ Is typography strong?

✓ Is hierarchy obvious?

✓ Is navigation simple?

✓ Does every section have purpose?

✓ Does it look original?

✓ Would a ₹10 lakh client trust this company?

✓ Does it feel fast?

✓ Would this still look good without animations?

If any answer is "No"

Improve the design before moving forward.

---

# FINAL DESIGN GOAL

The website should feel:

Smooth like Cuberto.

Clean like Linear.

Structured like Stripe.

Minimal like Apple.

Professional like Clay.

But when someone sees it they should say:

"This feels like Parvex."

Not

"This looks like Cuberto."
