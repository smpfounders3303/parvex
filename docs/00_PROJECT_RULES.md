# DESIGN THINKING PROCESS

Before generating any UI or writing any code, always follow this process:

Step 1: Analyze all provided design references.

Step 2: Identify common design patterns and explain why they create a premium experience.

Step 3: Propose a unique design direction for PARVEX that combines the best ideas without copying any website.

Step 4: Present the design strategy and wait for approval.

Step 5: Create a low-fidelity page structure (wireframe in text).

Step 6: After approval, build the production-quality UI.

Never skip directly to coding.

Always think before designing.

Always design before developing.
